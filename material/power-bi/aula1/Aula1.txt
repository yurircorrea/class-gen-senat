No Power Query:

- Fazer as transformações de dados: 
- Separar a localidade (guia transformar, dividir coluna, delimitador personalizado)
- Renomear uma coluna

- Inverter nome cliente para atender ao padrão do Brasil (via Adicionar coluna, coluna de exemplo) / Renomear para Nome Completo Cliente

De volta ao Power BI:
- Visual de Cartão: Campos - Faturamento; Formatação: Retirar rotulo da categoria, Adicionar Titulo, Formatar, Colocar em formato de moeda.
- Visual de cartão: Campos - Produto; Filtros (explicar a diferença de neste visual/nesta página/no documento): Produto, filtro n superior, n = 1, por valor (qtd vendida); Formatar como outro cartão (mostrar o pincel de formatação)
- Visual de Gráfico de Barras: Eixo x: Faturamento; Eixo y: Marcas; Formatar o titulo; Remover o rótulo do eixo X; Colocar o rotulo de dados nas barras (ao invés do eixo X). 
- Mostrar no gráfico como a seleção de uma marca específica muda os valores
- Gráfico de colunas com linhas: Eixo X: Data venda (Deixar ano e mês); Eixo Y: Faturamento; Eixo Y linha: Quant. vendida; Formatar gráfico
- Para o próximo gráfico: Opções e configurações - Segurança - Mostrar Mapas
- Gráfico de Mapa: Continente; Tamanho da Bolha: Faturamento
